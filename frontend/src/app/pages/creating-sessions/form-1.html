FIRST-TIME USER GUIDE

Page 1: Creating a New Session

Step 1: Filling The Required Information

Overview

The Create Individual Session page allows users to configure and review session parameters before launching.

  1. Session Information
    • Session Name: Input field to name the session.
    • Session Description: Optional field for additional session notes.
  2. Session Settings
    • Sets evaluator counts, sample quantities, and host participation preferences.
  3. Select Coffee Samples
    • Includes a search bar, a button to create samples, and a table to select coffee samples for evaluation.
  4. Session Summary
    • Displays configured session parameters along with Create Session and Cancel buttons.

Step 2: Session Management

Overview

The Session Management page monitors participant activity and controls session status.

  1. Session Header & Status
    • Includes the Open Evaluation button and the Session Elapsed Time timer.
  2. Invite Evaluators
    • Provides a shareable session link with a Copy button and availability status.
  3. Current Evaluators
    • Displays joining evaluators, their roles, and evaluation progress.
  4. Samples & Session Actions
    • Lists assigned coffee samples and includes the Finalize Session button.

Step 3: Session Start

Overview

The Session Start page prompts the evaluator to initiate their evaluation.

  1. Session Header & Timer
    • Your evaluation time: Live timer tracking individual evaluation duration.
  2. Evaluation Controls
    • Begin Evaluation Button: Action button to start timing and enter the evaluation form.
